# Sistema de Ventas

## Descripción
El Sistema de Ventas es una aplicación de escritorio para gestionar facturación, inventario y clientes en pequeñas y medianas empresas. Automatiza el registro de ventas, reduce errores y genera reportes de ingresos diarios.
